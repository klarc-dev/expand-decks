## 1. Nature juridique et finalité

### 1.1. Définition

1. L’IP Box française est un régime optionnel d’imposition séparée applicable à certains revenus nets tirés d’actifs incorporels éligibles. Sources : Article 238 CGI ; BOI-BIC-BASE-110.
2. Le régime porte sur les résultats nets de cession, concession ou sous-concession d’actifs éligibles. Sources : Article 238 CGI ; BOI-BIC-BASE-110-10 §270-310.
3. Le taux réduit applicable à la fraction éligible est de 10 %. Sources : CGI art. 219 ; BOI-BIC-BASE-110-30 §340 ; LF 2019 art. 37.
4. Le régime actuel est issu de l’article 37 de la loi de finances pour 2019, applicable aux exercices ouverts à compter du 1er janvier 2019. Sources : LF 2019 art. 37 ; BOI-BIC-BASE-110.

### 1.2. Finalité

1. Le régime transpose l’approche OCDE dite modified nexus approach. Sources : OCDE Action 5 ; OCDE Agreement on Modified Nexus Approach ; AN rapport 1302 ; Cour des comptes 2025.
2. L’avantage fiscal est conditionné à un lien entre le revenu de PI et les dépenses de R&D supportées par le contribuable ou par des tiers indépendants. Sources : OCDE Nexus ; Article 238 CGI ; BOI-BIC-BASE-110-30 §170-240.

## 2. Cadre international et européen

### 2.1. OCDE

1. L’OCDE impose que le revenu bénéficiant d’un régime préférentiel soit proportionnel aux dépenses qualifiantes de R&D supportées pour développer l’actif. Sources : OCDE Action 5 ; OCDE Nexus.
2. La formule conceptuelle OCDE est : dépenses qualifiantes / dépenses totales × revenu total de l’actif IP. Sources : OCDE Action 5 ; OCDE Nexus.
3. Les dépenses qualifiantes incluent la R&D interne et la R&D externalisée à des parties indépendantes. Source : OCDE Nexus.
4. Les coûts d’acquisition et la R&D externalisée auprès de parties liées sont exclus du numérateur OCDE. Source : OCDE Nexus.
5. L’OCDE autorise une majoration limitée de 30 % des dépenses qualifiantes, sans dépassement des dépenses totales. Source : OCDE Nexus.
6. Les actifs marketing, notamment les marques, sont exclus. Source : OCDE Nexus.

### 2.2. Union européenne

1. Le Groupe Code de conduite de l’UE a repris l’approche nexus comme standard des régimes patent box / IP box. Source : Conseil UE ST 16100/14.
2. Les anciens régimes non conformes devaient être fermés aux nouveaux entrants au plus tard le 30 juin 2016. Source : Conseil UE ST 16100/14.
3. Les avantages des anciens régimes non conformes devaient prendre fin au plus tard le 30 juin 2021. Source : Conseil UE ST 16100/14.
4. La France a réformé son régime pour répondre aux standards OCDE et UE. Sources : LF 2019 art. 37 ; AN rapport 1302 ; Cour des comptes 2025.

## 3. Bénéficiaires

### 3.1. Entreprises dans le champ

1. Le régime peut s’appliquer aux entreprises industrielles, commerciales, agricoles ou libérales. Source : BOI-BIC-BASE-110-10 §1.
2. Le régime peut s’appliquer aux entreprises relevant de l’IR soumises à un régime réel. Source : BOI-BIC-BASE-110-10 §1.
3. Le régime peut s’appliquer aux entreprises passibles de l’IS. Source : BOI-BIC-BASE-110-10 §1.
4. Le régime peut s’appliquer aux sociétés de personnes relevant de l’article 8 CGI, avec imposition au niveau des associés. Sources : BOI-BIC-BASE-110-10 §1 ; BOI-BIC-BASE-110-30 §350-355.

### 3.2. Personnes hors champ

1. Les inventeurs personnes physiques relevant de l’article 93 quater CGI ne relèvent pas du régime de l’article 238 CGI. Source : BOI-BIC-BASE-110-10 §1.

## 4. Actifs incorporels éligibles

### 4.1. Brevets et titres assimilés

1. Les brevets sont éligibles. Sources : Article 238 CGI ; BOI-BIC-BASE-110-10 §10-60.
2. Les certificats d’utilité sont éligibles. Sources : Article 238 CGI ; BOI-BIC-BASE-110-10 §10 et §70.
3. Les certificats complémentaires de protection rattachés à un brevet sont éligibles. Sources : Article 238 CGI ; BOI-BIC-BASE-110-10 §10 et §80.
4. Les titres étrangers équivalents peuvent être éligibles. Source : BOI-BIC-BASE-110-10 §20.
5. Les titres doivent en principe être en cours de validité. Source : BOI-BIC-BASE-110-10 §30.
6. Les brevets et certificats d’utilité en cours de délivrance peuvent être admis provisoirement sous conditions. Source : BOI-BIC-BASE-110-10 §30.

### 4.2. Certificats d’obtention végétale

1. Les certificats d’obtention végétale français sont éligibles. Sources : Article 238 CGI ; BOI-BIC-BASE-110-10 §90.
2. Les titres étrangers équivalents et communautaires sont éligibles. Source : BOI-BIC-BASE-110-10 §90.
3. Les certificats doivent être en cours de validité. Source : BOI-BIC-BASE-110-10 §100.

### 4.3. Logiciels protégés par droit d’auteur

1. Les logiciels protégés par le droit d’auteur sont éligibles. Sources : Article 238 CGI ; BOI-BIC-BASE-110-10 §110.
2. Les versions successives ou simultanées peuvent être comprises dans le champ. Source : BOI-BIC-BASE-110-10 §110.
3. Le logiciel doit présenter un caractère original. Source : BOI-BIC-BASE-110-10 §110.
4. L’absence de dépôt formel rend nécessaire une documentation probatoire de l’originalité. Source : BOI-BIC-BASE-110-10 §110 ; sources praticiennes concordantes.

### 4.4. Procédés de fabrication industriels

1. Certains procédés industriels non brevetables sont éligibles. Sources : Article 238 CGI ; BOI-BIC-BASE-110-10 §120.
2. Le procédé doit résulter d’opérations de recherche. Source : BOI-BIC-BASE-110-10 §140.
3. Le procédé doit être l’accessoire indispensable de l’exploitation d’un brevet ou certificat d’utilité. Sources : BOI-BIC-BASE-110-10 §150-160.
4. Le procédé doit faire l’objet de la même cession, concession ou sous-concession que le brevet ou certificat d’utilité. Sources : BOI-BIC-BASE-110-10 §170-200.

### 4.5. Actifs historiquement discutés mais non éligibles actuellement

1. Les inventions brevetables certifiées par l’INPI ont figuré dans l’historique du régime post-2019. Sources : LF 2019 art. 37 ; AN rapport 1302.
2. Les revenus issus des inventions dont la brevetabilité a été certifiée par l’INPI ont été exclus du dispositif de taxation à 10 % par la loi de finances pour 2023. Source : actualité liée BOI-BIC-BASE-110-10, version 03/05/2023.
3. En droit positif actuel, les inventions seulement certifiées brevetables par l’INPI ne doivent pas être listées comme actifs éligibles. Source : BOI-BIC-BASE-110-10, actualité 03/05/2023.

## 5. Actifs et éléments exclus

1. Les marques sont exclues. Sources : OCDE Nexus ; article 238 CGI par liste limitative.
2. Les noms commerciaux et actifs marketing analogues sont exclus. Sources : OCDE Nexus ; article 238 CGI par liste limitative.
3. Les dessins et modèles ne sont pas éligibles. Sources : Article 238 CGI par liste limitative ; OCDE Nexus.
4. Les droits d’auteur autres que les logiciels protégés ne sont pas visés. Sources : Article 238 CGI ; BOI-BIC-BASE-110-10 §110.
5. Le savoir-faire autonome non rattaché à un procédé industriel accessoire n’est pas éligible. Source : BOI-BIC-BASE-110-10 §120-200.
6. Les prestations de services ne sont pas des actifs éligibles. Sources : Article 238 CGI ; BOI-BIC-BASE-110-10 §320-350.
7. Les revenus de support, maintenance, hébergement, formation, assistance ou configuration doivent être exclus ou ventilés lorsqu’ils sont inclus dans un contrat global. Sources : BOI-BIC-BASE-110-10 §340-350 ; sources praticiennes CMS.

---

## 6. Opérations éligibles

### 6.1. Cession

1. La cession d’un actif éligible peut entrer dans le régime. Sources : Article 238 CGI ; BOI-BIC-BASE-110-10 §270-280.
2. La cession s’entend d’une opération entraînant la sortie de l’actif de l’entreprise. Source : BOI-BIC-BASE-110-10 §280.
3. La cession d’un actif acquis à titre onéreux depuis moins de deux ans n’est pas éligible. Source : BOI-BIC-BASE-110-20 §290-310.
4. La cession entre entreprises liées n’est pas éligible. Source : BOI-BIC-BASE-110-20 §320.

### 6.2. Concession

1. La concession de licence d’exploitation d’un actif éligible peut entrer dans le régime. Sources : Article 238 CGI ; BOI-BIC-BASE-110-10 §290.
2. La licence peut être exclusive ou non exclusive. Source : BOI-BIC-BASE-110-10 §290.
3. Pour les logiciels, l’accès peut se faire à distance via une plateforme ou par installation sur un équipement du client. Source : BOI-BIC-BASE-110-10 §310.

### 6.3. Sous-concession

1. La sous-concession d’une licence d’exploitation d’un actif éligible peut entrer dans le régime. Sources : Article 238 CGI ; BOI-BIC-BASE-110-10 §300.

---

## 7. Contrats mixtes et ventilation

1. Si le contrat porte exclusivement sur des actifs éligibles remplissant les conditions, l’ensemble du contrat peut relever du régime. Source : BOI-BIC-BASE-110-10 §320-330.
2. Si le contrat distingue le prix des actifs éligibles et des éléments non éligibles, seul le prix correspondant aux actifs éligibles peut relever du régime. Source : BOI-BIC-BASE-110-10 §340.
3. Si le contrat fixe un prix global, l’entreprise doit déterminer la quote-part rémunérant les actifs éligibles. Source : BOI-BIC-BASE-110-10 §350.
4. La méthode de ventilation doit être adaptée, objective et documentée. Source : BOI-BIC-BASE-110-10 §350.

---

## 8. Option

1. Le régime est optionnel. Sources : Article 238 CGI ; BOI-BIC-BASE-110-20 §60.
2. L’option est formulée dans la déclaration de résultat de l’exercice. Sources : Article 238 CGI ; BOI-BIC-BASE-110-20 §80.
3. L’option n’est pas globale. Source : BOI-BIC-BASE-110-20 §90.
4. L’option peut être formulée par actif. Sources : Article 238 CGI ; BOI-BIC-BASE-110-20 §90.
5. L’option peut être formulée par bien ou service. Sources : Article 238 CGI ; BOI-BIC-BASE-110-20 §90.
6. L’option peut être formulée par famille de biens ou services. Sources : Article 238 CGI ; BOI-BIC-BASE-110-20 §90.
7. Le suivi par bien/service ou famille doit être justifié par l’impossibilité ou le caractère arbitraire d’un suivi plus fin. Sources : Article 238 CGI ; BOI-BIC-BASE-110-20 §90.
8. La méthode retenue doit être permanente et cohérente. Sources : Article 238 CGI ; BOI-BIC-BASE-110-20 §90.
9. Si l’entreprise cesse d’appliquer le régime pour un périmètre donné, elle perd définitivement le bénéfice du régime pour ce périmètre. Source : BOI-BIC-BASE-110-20 §110-120.

---

## 9. Résultat net éligible

1. Le résultat net est égal aux revenus tirés des actifs éligibles diminués des dépenses de R&D qui s’y rattachent directement. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §10.
2. Le résultat net peut être calculé par actif, bien/service ou famille selon le périmètre d’option. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §20.
3. Pour une cession, le revenu est le prix acquis au cours de l’exercice. Source : BOI-BIC-BASE-110-30 §30-40.
4. Pour une concession ou sous-concession, le revenu est constitué par les redevances contractuelles acquises. Source : BOI-BIC-BASE-110-30 §50.
5. Les dépenses retenues doivent être de R&D, avoir un lien direct avec les actifs, et être réalisées directement ou indirectement par l’entreprise. Source : BOI-BIC-BASE-110-30 §60-120.
6. Peuvent notamment être retenus : personnel de recherche, externalisation R&D, matières et fournitures R&D, équipements affectés à la R&D, création/acquisition d’actifs éligibles, frais de prise et maintenance des titres. Source : BOI-BIC-BASE-110-30 §80.
7. Sont exclus : frais généraux, terrains/bâtiments, emprunts, frais de défense des droits, normalisation, veille technologique, frais de cession. Source : BOI-BIC-BASE-110-30 §80.
8. Au premier exercice de revenu, le résultat net est aussi diminué des dépenses engagées depuis l’exercice d’option. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §140.
9. Un résultat net déficitaire s’impute sur les résultats nets bénéficiaires ultérieurs du même actif ou groupe. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §360.

## 10. Ratio nexus

### 10.1. Fonction

1. Le ratio nexus détermine la fraction du résultat net pouvant bénéficier du taux réduit. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §1 et §170.
2. Le ratio reflète la part de R&D qualifiante supportée par le contribuable ou des tiers indépendants. Sources : OCDE Nexus ; BOI-BIC-BASE-110-30 §170-200.

### 10.2. Formule

```text
Ratio nexus = [(A + B) × 1,30] / [A + B + C + D]

A = R&D réalisée directement par l’entreprise
B = R&D confiée à des entreprises non liées
C = R&D confiée à des entreprises liées
D = coûts d’acquisition des actifs incorporels éligibles
```

Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §170-240 ; AN rapport 1302.

### 10.3. Numérateur

1. Le numérateur inclut la R&D en lien direct avec la création et le développement de l’actif. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §170.
2. Le numérateur inclut la R&D réalisée directement par le contribuable. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §170.
3. Le numérateur inclut la R&D externalisée auprès d’entreprises non liées. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §170 et §190.
4. Le numérateur exclut la R&D externalisée auprès d’entités liées. Source : BOI-BIC-BASE-110-30 §190.
5. Le numérateur exclut les coûts d’acquisition d’actifs incorporels éligibles. Source : BOI-BIC-BASE-110-30 §190.

### 10.4. Dénominateur

1. Le dénominateur inclut l’ensemble des dépenses de R&D ou d’acquisition liées à l’actif. Source : Article 238 CGI.
2. Le dénominateur inclut les dépenses du numérateur. Source : BOI-BIC-BASE-110-30 §200.
3. Le dénominateur inclut la R&D externalisée auprès d’entités liées. Source : BOI-BIC-BASE-110-30 §200.
4. Le dénominateur inclut les coûts d’acquisition d’actifs incorporels éligibles. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §200.
5. Les redevances de concession dues par un sous-concédant sont retenues seulement au dénominateur. Source : BOI-BIC-BASE-110-30 §210.

### 10.5. Uplift et plafond

1. Les dépenses du numérateur sont retenues pour 130 % de leur montant. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §240.
2. La majoration correspond à l’uplift OCDE. Sources : OCDE Nexus ; BOI-BIC-BASE-110-30 §240.
3. Le ratio ne peut excéder 100 %. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §240.
4. Le rapport est arrondi au nombre entier supérieur. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §240.

---

## 11. Temporalité du ratio

1. Le ratio est calculé au titre de chaque exercice. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §230.
2. Le ratio tient compte des dépenses de l’exercice et des exercices antérieurs. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §230.
3. Les dépenses au numérateur et au dénominateur sont cumulées depuis l’origine. Source : BOI-BIC-BASE-110-30 §230.
4. L’entreprise doit suivre toutes les dépenses de R&D afférentes à chaque actif ou groupe, y compris celles antérieures à l’exercice d’option. Source : BOI-BIC-BASE-110-30 §230.
5. Pour 2019 et 2020, une méthode transitoire permettait un calcul global au niveau de l’entreprise. Sources : LF 2019 art. 37 ; BOI-BIC-BASE-110-30 §280.
6. À compter de 2021, l’entreprise peut ne retenir, pour les dépenses antérieures, que celles réalisées au titre des exercices ouverts à compter du 1er janvier 2019. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §290-300.

---

## 12. Application du taux réduit

1. Lorsque le résultat net est bénéficiaire, le ratio nexus est appliqué à ce résultat. Source : BOI-BIC-BASE-110-30 §330-340.
2. La fraction obtenue est déduite extra-comptablement du résultat imposable au taux normal. Source : BOI-BIC-BASE-110-30 §340.
3. Cette fraction est imposée séparément au taux réduit de 10 %. Sources : CGI art. 219 ; BOI-BIC-BASE-110-30 §340.
4. Pour une société de personnes, l’option est exercée au niveau de la société, le résultat net et le ratio sont déterminés à son niveau, puis imposés au nom des associés selon leurs droits. Source : BOI-BIC-BASE-110-30 §350-355.

---

## 13. Obligations déclaratives

1. L’entreprise doit joindre une annexe à sa déclaration de résultat. Sources : Article 238 CGI ; BOI-BIC-BASE-110-20 §140-160.
2. L’annexe détaille les calculs pour chaque actif, bien/service ou famille. Sources : Article 238 CGI ; BOI-BIC-BASE-110-20 §150.
3. L’annexe détaille le résultat net et le ratio nexus. Source : BOI-BIC-BASE-110-20 §150.
4. Le formulaire est l’annexe n° 2468-SD, CERFA n° 16008. Sources : BOI-BIC-BASE-110-20 §160 ; https://www.impots.gouv.fr/formulaire/2468-sd/determination-du-resultat-net-densemble-de-cession-de-concession-ou-de-sous-conc
5. Le défaut de production peut entraîner la déchéance de l’option pour le périmètre concerné. Source : BOI-BIC-BASE-110-20 §170.
6. Le défaut de production dans les délais entraîne une amende de 150 €. Source : BOI-BIC-BASE-110-20 §180.
7. Les omissions ou inexactitudes entraînent une amende de 15 € par omission ou inexactitude, avec plancher de 60 € et plafond de 10 000 €. Source : BOI-BIC-BASE-110-20 §180.

---

## 14. Obligations documentaires

1. Les entreprises ayant opté doivent tenir une documentation à disposition de l’administration. Sources : LPF L13 BA ; BOI-BIC-BASE-110-20 §190.
2. La documentation justifie la détermination du résultat net soumis au taux réduit. Sources : LPF L13 BA ; BOI-BIC-BASE-110-20 §190.
3. Elle comprend une description générale de l’organisation des activités de R&D. Sources : LPF L13 BA ; BOI-BIC-BASE-110-20 §200.
4. Elle comprend une liste et description détaillée des actifs ou groupes d’actifs. Sources : LPF L13 BA ; BOI-BIC-BASE-110-20 §200.
5. Elle comprend une présentation du ratio nexus et de son suivi. Sources : LPF L13 BA ; BOI-BIC-BASE-110-20 §200.
6. Elle comprend une présentation de la méthode de répartition des frais. Sources : LPF L13 BA ; BOI-BIC-BASE-110-20 §200.
7. Elle doit être sous format électronique exploitable. Source : BOI-BIC-BASE-110-20 §210.
8. Les PDF image scannés sont proscrits. Source : BOI-BIC-BASE-110-20 §210.
9. Elle doit être disponible à la date d’engagement de la vérification. Source : BOI-BIC-BASE-110-20 §220.
10. Elle doit être actualisée pendant toute la période couverte par l’option. Source : BOI-BIC-BASE-110-20 §220.
11. En cas de documentation absente ou partielle, l’administration adresse une mise en demeure avec délai de 30 jours. Source : BOI-BIC-BASE-110-20 §230.
12. L’absence persistante entraîne l’amende de l’article 1740-0 C CGI. Sources : CGI 1740-0 C ; BOI-BIC-BASE-110-20 §260.
13. L’amende est égale à 5 % du résultat net imposé au taux réduit pour les actifs concernés. Sources : CGI 1740-0 C ; BOI-BIC-BASE-110-20 §260.

---

## 15. Rapport de remplacement

1. Dans des circonstances exceptionnelles, l’entreprise peut demander un rapport de remplacement. Sources : Article 238 CGI ; BOI-BIC-BASE-110-30 §310.
2. Le rapport représente la proportion de valeur de l’actif attribuable aux activités de R&D réalisées par l’entreprise ou par des tiers non liés. Source : BOI-BIC-BASE-110-30 §310.
3. Le ratio standard doit être supérieur à 32,5 %. Source : BOI-BIC-BASE-110-30 §320.
4. Le rapport de remplacement doit être significativement supérieur au ratio standard. Source : BOI-BIC-BASE-110-30 §320.
5. L’écart doit résulter de circonstances exceptionnelles indépendantes de l’entreprise. Source : BOI-BIC-BASE-110-30 §320.
6. Un agrément préalable est nécessaire. Source : BOI-BIC-BASE-110-30 §320.
7. L’agrément est valable cinq exercices sous réserve du maintien des conditions. Source : BOI-BIC-BASE-110-30 §320.
8. Le rapport de remplacement ne bénéficie pas de la majoration de 30 %. Source : BOI-BIC-BASE-110-30 §320.

---

## 16. Pièges pratiques

1. Pour les logiciels, il faut documenter l’originalité. Source : BOI-BIC-BASE-110-10 §110.
2. Pour le SaaS, il faut distinguer la composante droit d’usage logiciel des services d’hébergement, support, maintenance, formation ou assistance. Sources : BOI-BIC-BASE-110-10 §310 et §340-350.
3. Pour les produits numériques composites, seules les composantes correspondant à un actif éligible peuvent être retenues. Sources : Article 238 CGI ; BOI-BIC-BASE-110-10 §340-350.
4. La R&D sous-traitée à une entité liée est exclue du numérateur et incluse au dénominateur. Sources : BOI-BIC-BASE-110-30 §190-200.
5. Si une entité liée refacture sans marge une prestation réalisée par un tiers indépendant, la dépense peut être assimilée à une externalisation auprès d’un tiers non lié sous justification. Source : BOI-BIC-BASE-110-30 §190.
6. Les coûts d’acquisition sont exclus du numérateur et inclus au dénominateur. Sources : BOI-BIC-BASE-110-30 §190-200.
7. Les dépenses communes doivent être réparties selon leur utilisation réelle ou une clé pertinente justifiable. Source : BOI-BIC-BASE-110-30 §110.
8. Une répartition globalement forfaitaire de toute la R&D est proscrite. Source : BOI-BIC-BASE-110-30 §110.

```text
Base imposable à 10 %
=
Résultat net éligible
×
min(
  100 %,
  [(R&D interne + R&D tiers indépendants) × 130 %]
  /
  [R&D interne + R&D tiers indépendants + R&D liée + coûts d’acquisition]
)
```
