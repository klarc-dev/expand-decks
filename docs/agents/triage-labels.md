# Triage labels

The engineering skills use five canonical triage state roles. Their tracker labels are:

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Waiting for actionable information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned, including already-implemented requests |

Every triaged issue must also have exactly one category label: `bug` or `enhancement`.

When triage posts an issue comment, the comment must begin with:

> *This was generated by AI during triage.*
